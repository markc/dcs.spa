# 2026-06-17

## Tour deck: panel reorder, narrow-sidebar containment, themed code panels

Worked the left-sidebar Tour deck (`docs/index.html`, `docs/site.css`).

### Panel reorder
- Moved the Tour panel from #1 to #4 so the carousel opens on **Navigation**.
  Order is now Navigation → About → Docs → Tour. Done as an exact line-slice
  (Mix) to avoid transcription risk; carousel index 0 = Navigation, active dot
  unchanged.

### Narrow-sidebar containment (the hard one)
- The deck ignored the sidebar width and clipped its content at the edge.
- Measured the computed width down the chain with headless Chrome + DevTools
  Protocol: panel/viewport/track/slide were all correct sidebar width (81px),
  but **`.deck` itself jumped to ~1000px**. It's a flex item inside the flush
  `.panel-content` with the default `min-width:auto`, so the widest slide (the
  code `<pre>`) forced the whole deck wide and everything inside inherited it.
- Fix: `min-width:0` on **`.deck`** (the real lever) + `.deck-viewport`, plus
  defensive caps on `.sidebar-left .panel:has(.deck)` and `.deck-slide`. Verified
  the whole chain collapses to the sidebar width afterwards.
- Added a `@container (max-width:440px)` query that folds the deck's figure rows
  and the slide/fade compare grid to a single column when the sidebar is narrow
  (mobile full-width or a slim pinned desktop sidebar).

### Removed deck slide-up
- Deleted the per-slide entry stagger (`translateY` reveal + `html.preload`
  hold). Section `.reveal` + `initScrollReveal` scroll-in is a separate
  mechanism and left untouched.

### Code/stack panels — mode + theme aware
- `.deck-code` (code `<pre>`) and `.deck-stack` (persistence list) had a
  `color-mix(var(--fg-primary)…)` background that only resolved dark in light
  mode — in dark mode it flipped light and the light syntax text was unreadable.
- Now built from theme tokens: `--code-bg = color-mix(--bg-primary 92%,
  --accent 8%)` (flips with mode, carries the scheme hue), `--code-fg =
  --fg-primary`. Syntax tokens keep their distinct hues but their lightness
  flips via a mode-aware `--code-token-l` (0.46 light / 0.82 dark).
- Verified across light/dark × ocean/crimson: bg L 0.94↔0.17, fg L 0.25↔0.95,
  hue tracks the scheme (220→25), strong contrast throughout.
