## Drag-resizable sidebars

- Added drag-to-resize on each sidebar's **inner edge** (`docs/base.css`, `docs/base.js`).
- `base.css`: new `.sidebar-resizer` — 10px hit area straddling the 1px edge border, `ew-resize` cursor, 2px accent line on hover/drag. `body.resizing` kills the slide transition + disables text selection. Handle hidden below 768px.
- `base.js`: split `setSidebarWidth` into `applySidebarWidth` (DOM only, 1% precision) + `setSidebarWidth` (apply + persist; spinner path still snaps to step 10). `init()` injects a resize handle into each sidebar (no HTML change — consuming pages get it free) and wires `pointerdown/move/up/cancel`: live width var while dragging, persist to `base-state` only on release. `restore()` now applies stored widths **verbatim** (was snapping to step 10, which would round a dragged 37% up to 40% on reload).
