## Review pass: codex + /code-review + /security-review

Ran three reviews on the session's work and acted on the real findings.

- **codex-review** (`codex exec review --commit`, via CLI — the Codex MCP server isn't wired into this session) on the drag-resize commit: 1 finding (P3) — `.sidebar-resizer` left a 5px pointer-active strip at the viewport edges when a sidebar was closed (off-canvas inner edge lands on the viewport edge). Fixed in `base.css`: `pointer-events: none` by default, re-enabled via `.sidebar.open .sidebar-resizer`. Verified `pinSidebar()`/`restore()` always add `.open` when pinning, so pinned sidebars still resize. Amended into the commit + force-pushed.

- **/code-review high** on `base.js` + `base.css`: most candidates refuted (resize-on-pinned, width-10 falsy guard, panel-0 restore — all checked against source and cleared). One real fix: `state()` had no error handling, so a corrupt `base-state` value (invalid JSON) or storage-restricted context (private mode / sandboxed iframe) would throw on the first call and break `init()`/`restore()` with no self-heal. Wrapped read (→ `{}`) and write (no-op) in try/catch. Also guarded `restore()` tree code with `Array.isArray(s.treeExpanded)`.

- **/security-review** on `md.js` (the canonical reusable markdown renderer): found 4 real XSS gaps + 1 fetch gap. Root cause: `esc()` escaped only `& < >`, never `"`, and no URL scheme allowlist — so `[x](javascript:…)`, and attribute-quote breakout in img `alt`/`src` and link `href`, all executed. **Not live-exploitable on dcs.spa** (it renders only its own trusted `_doc`/`_spec`/`ai.txt`, uses its own `showDoc` with a `#_doc/` guard, and md.js's auto-init is dormant — no `data-md-auto`), but a genuine vuln for any downstream project that copies md.js and renders user markdown. Fixes in `md.js`: `safeUrl()` routes `javascript:`/`data:`/`vbscript:` to `#`; user quotes in attribute context encoded via a `\x05` placeholder restored to `&quot;` after `esc()` (avoids the `&`→`&amp;` double-escape that a naive `escapeAttr` would hit); `loadDoc()` now rejects schemes, protocol-relative, absolute, and `..` paths (same-origin relative only). Verified with a node harness: all 5 vectors neutralised, normal links/images/code still render.
